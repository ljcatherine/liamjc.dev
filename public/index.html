Nexus

Open source GitHub ↗ Docs ↗ nexus.liamjc.dev ↗

An AI IDE and home-lab control room for my iPhone, Windows PC and NixOS machine, plus a web client. Every client shares one security policy: the Debian server is read-only, and AI agents can never write to it. It's open source, with guides for building the whole system yourself.

  1. NexusiOS ↗Swift · iPhone app with SSH, host metrics and AI chat
  2. NexusWindows ↗Rust · egui IDE with Codex and Claude Code
  3. NexusNix ↗Rust · the same app for NixOS, in progress
  4. NexusOnline ↗Astro · Cloudflare Workers and Access
